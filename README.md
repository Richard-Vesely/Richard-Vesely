# Hi, I'm Richard 👋

I run **[Ardoremy](https://ardoremy.cz)** — science and coding camps and workshops for kids in the Czech Republic.
Most of what lives here is built for those kids: games they play, simulations they explore, and code they learn to write.

### 🎮 Games & learning tools
- **[Guess the Function](https://richard-vesely.github.io/Funkce_cviceni/)** — kids write Python in the browser (Pyodide) to crack a hidden function
- **[Artillery simulator](https://richard-vesely.github.io/Delostrelci_simulace/)** — program a projectile's trajectory in Python
- **[tank-battle](https://github.com/Richard-Vesely/tank-battle)** & **[prestrelka-server](https://github.com/Richard-Vesely/prestrelka-server)** — real-time multiplayer games (Node.js, Socket.IO) played at camps
- **[Kid web games](https://richard-vesely.github.io/kid-games-openclaw/)** — ten small browser games for younger kids

### 🔬 Science & simulations
- **[Dynamical systems](https://richard-vesely.github.io/dynamical-system-simulations/)** — Gray-Scott reaction-diffusion, Lotka-Volterra, WebGL shaders
- **[Vectors](https://richard-vesely.github.io/vectors/)** and **[projectile motion](https://richard-vesely.github.io/vertical_projectile_motion/)** — physics teaching tools

### 🔌 Hardware
- **[ArduinoProjekty](https://github.com/Richard-Vesely/ArduinoProjekty)** — Arduino & ESP32 sketches for kids' electronics workshops

**Stack:** TypeScript · React · Vite · Node.js · Supabase · Python · Arduino/C++
